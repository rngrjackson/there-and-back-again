TABA VERSION 0.2 — Illustrated Daily Tracker

Open index.html on your computer to preview. For reliable install and offline caching, serve over HTTPS (e.g. GitHub Pages).

This release adds Samsung Health steps/daily distance logging, a visual widget mockup, separate official intentional workout mileage, and merged JSON backups.

The 4x4 / 4x6 Samsung HOME SCREEN widget is not yet built. It requires a native Android component (AppWidgetProvider / Glance) and a shared storage bridge. This ZIP is a PWA prototype, not an APK.

No Samsung Health automatic integration, Google Drive sync, or Android widget is claimed. Local records remain on this device/browser. Export JSON backups regularly.
